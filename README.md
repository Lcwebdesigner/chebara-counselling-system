# Chebara Technical and Vocational College Online Counselling Booking Management System

A PHP/MySQL web application for counselling appointment booking and management.

## Technology
- HTML
- CSS
- JavaScript
- PHP
- MySQL

## Main roles
- Student
- Counsellor
- Administrator

## Setup
1. Import `database/database.sql` into MySQL.
2. Configure `includes/config.php` with the server database credentials.
3. Upload the project to a PHP/MySQL host such as InfinityFree.
4. Create an admin account securely using a PHP `password_hash()` value.
5. Test registration, login, slot creation, booking, confirmation, cancellation and reports.

## Security note
Do not commit real database passwords or API credentials to a public GitHub repository.

## Scope
The application manages counselling appointments and records. It does not perform automated diagnosis or replace a professional counsellor.
